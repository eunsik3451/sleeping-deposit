# 잠자는 예수금 깨우기 (프로토타입)

유진투자증권 사내 AX 공모전(고객의 투자경험 혁신) 출품용 데모입니다. 고객이 따로 입력하지 않아도 계좌·거래 데이터만으로 **쉬고 있는 예수금 때문에 놓친 이자**를 찾아 금액으로 보여주고, 알맞은 때·채널·문구로 알려 고객이 직접 RP를 매수하거나 예수금 자동 RP를 신청하기까지 이어지게 합니다.

> 데이터는 전부 가상입니다. 금리·진단 유효기간·광고 기준은 데모용 가정값이라 회사 실제 값으로 확인이 필요합니다 (`config.yaml`의 `# 확인 필요`).

## 실행

데이터와 가상환경이 준비돼 있으면 **`run_demo.bat`을 더블클릭**하고 브라우저에서 http://localhost:8501 을 열면 됩니다. 검은 창을 닫으면 앱도 꺼집니다.

처음 설치할 때:

```bash
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python scripts\generate_demo_data.py --seed 42   # 가상 데이터 300명 × 180일
.venv\Scripts\python -m pytest -q                             # 테스트 (C1~C11, N1~N9 포함)
.venv\Scripts\python -m streamlit run app\main.py             # http://localhost:8501
```

## 화면

| 화면 | 보여주는 것 |
|---|---|
| 고객 앱 화면 | 고객 본인이 앱에서 보는 화면 재현. 이번 달 못 받은 이자 / 깨우면 1년에 더 받을 이자 / 깨운 뒤 받은 이자, 6개월 추이, 유형별 카드와 실행 버튼, **이 고객에게 나가는 알림 예시(휴대폰 화면)** |
| 항목 한눈에 | 예수금(원화·달러·매수 대기·상환금), 해외주식 양도세, 공개매수 — 찾는 방법·제안·알림 예시 |
| PB 고객별 현황 | 고객마다 쉬는 예수금과 항목별로 놓치고 있는 금액, 마감 임박 순 확인, 고객 선택 시 알림 미리보기 |
| 알림 미리보기 | 하루 배치가 만든 발송함. 광고 동의·야간·빈도 제한으로 보류·변경된 건 |
| PB 콜리스트 | 큰 금액·진단 만료·광고 미동의 고객과 통화 스크립트 |
| 회사 대시보드 | 예수금 활용률, 유형별 놓친 이자, 알림 퍼널, 보류 사유 |
| 설정 | 기준일·금리·기준값을 바꾸면 즉시 다시 계산 |

## 90초 데모

1. 고객 앱 화면 → **P003**: "8,000만원이 90일째" 카드, 근거 보기(버퍼 설명)
2. "투자성향 다시 진단하기" → 진단 완료 → "예수금 자동 RP 신청" → 카드가 "깨운 뒤 받은 이자"로 바뀜
3. **P001**: 같은 노는 돈이어도 매매대기형이라 예수금 자동 RP만, 달러는 외화 RP
4. 알림 미리보기: P002 상환금 알림(정보성), 광고 동의 없는 고객은 PB 통화로, "야간 이동" 필터
5. PB 콜리스트 → P002 통화 스크립트
6. 회사 대시보드: 활용률, 퍼널, 보류 사유
7. 설정에서 최소 금액·주간 알림 수를 바꾸면 결과가 즉시 바뀜

같은 순서가 앱 사이드바의 "90초 데모 순서"에도 있습니다. 끝나면 사이드바의 "데모 처음으로 되돌리기"를 누릅니다.

## 원칙

- 돈 계산은 결정론적 엔진만 합니다. 문장은 템플릿에 계산값을 채우고, 검증기가 숫자 일치·정보성 금칙어·글자 수를 확인합니다. 외부 LLM 호출 없음.
- 회사 수익이 줄어드는 제안(환전 수수료 비교, 저보수 상품 전환)은 다루지 않습니다.
- 실제 주문·발송은 하지 않습니다 (데모 모달, 발송함 미리보기).
- 직원은 고객 대신 가입·실행할 수 없습니다. 가입은 고객이 앱에서 본인 인증 후 직접 하고, PB는 안내와 통화 결과 기록만 합니다.

자세한 명세와 진행 기록은 `CLAUDE.md`에 있습니다.
