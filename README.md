# 잠자는 예수금 깨우기 (프로토타입)

유진투자증권 사내 AX 공모전(고객의 투자경험 혁신) 출품용 데모입니다. 고객이 따로 입력하지 않아도 계좌·거래 데이터만으로 **잠자는 예수금 때문에 놓친 이자**와 **해외주식 양도세·연금저축 세액공제·유상증자 청약·펀드/ELS 만기처럼 잊기 쉬운 일정**을 금액으로 보여주고, 알맞은 때·채널·문구로 알려 고객이 직접 실행하기까지 이어지게 합니다.

**사이트:** https://eunsik3451.github.io/sleeping-deposit/

> 고객·종목·상품명은 전부 가상입니다. 금리는 유진투자증권 홈페이지 기준(예탁금 이용료 0.60%, 챔피언CMA(RP형) 2.75%, 2026-08-28)이고, 외화 RP 금리·진단 유효기간·광고 기준은 확인이 필요한 가정값입니다 (`config.yaml`의 `# 확인 필요`).

## 구조

- `engine/` 규칙 엔진 (금액 계산은 여기서만). R1 잠자는 예수금, R2 해외주식 양도세, R3 유상증자 청약 권리, R4 펀드·ELS 만기, R5 연금저축 세액공제
- `notify/` 알림 트리거·정책(수신 동의, 야간 제한, 빈도 제한, 중복 방지)·발송함·월간 리포트
- `messages/` 알림 템플릿과 검증기 (문장 속 숫자가 계산값과 같은지, 정보성에 상품명·금리·가입 권유가 없는지, 글자 수)
- `site/` 웹사이트 (HTML·JavaScript, 서버 없음). `site/data.js`는 엔진 결과를 내보낸 파일

## 다시 만들기

```bash
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pytest -q                 # 테스트
.venv\Scripts\python scripts\export_site.py       # 가상 고객 300명으로 엔진을 돌려 site/data.js 생성
```

`site/index.html`을 브라우저로 열면 그대로 볼 수 있습니다. GitHub Pages에는 `site/` 폴더 내용이 올라갑니다.

## 화면

| 화면 | 보여주는 것 |
|---|---|
| 고객 앱 화면 | 휴대폰 안에 실제 앱처럼: 잠금화면 알림 → 앱(깨우면 1년에 받을 이자, 6개월 추이, 함께 챙길 것) → 바텀 시트(자동 RP 신청, 재진단, RP 맡기기, 항목 상세). 옆 패널에 고객 선택·시연 순서·알림 예시·계산 근거. `#customer/P003/home`이면 앱에서 바로 시작 |
| 항목 한눈에 | 찾는 방법·안내·알림 시점, 금리 기준, 다루지 않는 것 |
| PB 아침 브리핑 | 오늘 먼저 연락할 고객(반대매매 위험·경고 → 마감 임박 → 급등락), 어제 시장 지수·보유 종목 이슈, 14일 안 마감 일정, 연락 기록 |
| 고객 한 명 화면 (`#client/고객번호`, PB용) | 잠자는 예수금 진단·예수금 추이·함께 챙길 것·보유 종목(신용 위험도)·받은 알림, 오른쪽에 최근 통화 요약·해야 할 일·케어 일정 달력. **통화 녹음 분석**: 녹음 파일을 올리면 브라우저 안에서 받아쓰고(Whisper) PB가 녹취록을 고친 뒤 요약·고객 요청·PB 약속·준법 점검·할 일을 정리해 저장 |
| (이전) 고객 전체 보기 | 예수금·달러·주식·신용 한눈에, 챙길 것, 보유 종목(신용 위험도), 6개월 예수금, 연락 기록 입력·이력, 받은 알림 |
| PB 고객 관리 | 오늘 연락할 고객·마감 임박·전체 고객을 한 화면에서. 고객을 고르면 챙길 것, 단계별 통화 스크립트, 근거, 처리 버튼 |
| 알림 미리보기 | 최근 30일 하루 배치가 만든 발송함. 광고 동의·야간·빈도 제한으로 보류·변경된 건 |
| 회사 대시보드 | 예수금 활용률, 유형별 놓친 이자, 세금·권리·만기 항목, 알림 퍼널, 보류 사유 |

## 90초 데모

1. 고객 앱 화면 → **P003**: 잠금화면 알림 → 앱, "8,000만원이 90일째"와 근거, 펀드 만기 D-10
2. "예수금 자동 RP"로 깨우기 → "깨운 뒤 받은 이자"로 바뀜
3. **P001**: 매매대기형이라 예수금 자동 RP만, 달러는 외화 RP, 유상증자 청약 마감 D-5, 양도세 88만원
4. 알림 미리보기: P002 상환금 알림(정보성), 광고 동의 없는 고객은 PB 통화로, 야간 예정 광고는 다음 날 오전으로
5. PB 고객 관리 → 고객 선택 → 단계별 통화 스크립트
6. 회사 대시보드: 활용률, 퍼널, 보류 사유

데모 버튼으로 바꾼 상태는 보는 사람의 브라우저에만 저장됩니다. "데모 처음으로"로 되돌릴 수 있습니다.

## 원칙

- 금액은 규칙 엔진만 계산하고 문장은 숫자를 바꿀 수 없습니다.
- 직원(PB)은 고객 대신 가입·실행하지 않습니다. 가입은 고객이 앱에서 본인 인증 후 직접 합니다.
- 예수금 자동 RP는 주식이나 펀드를 대신 사고팔지 않습니다. 정한 금액을 넘는 예수금만 RP에 넣고 쓸 때 자동으로 뺍니다.
- 양도세·청약·만기 안내는 정보 제공이며 매매·청약·재투자를 권유하지 않습니다.
- 회사 수익이 줄어드는 제안(환전 수수료 비교 등)과 유진 미취급 상품(IRP·발행어음 등)은 다루지 않습니다.
